## 第九篇｜应用训练系统：把力量放进真实任务里

这一分册只解决一件事：**当训练目标、时间、装备、恢复状态发生变化时，怎么保住最重要的能力。**

原则没有变：高质量重复优先，力量服务任务，不为了疲劳感而训练。

### 35. GTG + Daily Dose：高频、低量、永不力竭

**教程视频：** [BV13GuS6DE9A](https://www.bilibili.com/video/BV13GuS6DE9A)

> GTG 和 Daily Dose 的共同核心都是：**把训练频率拉高，把单次训练量压低，让每一次重复都保持新鲜。** 但两者不是同一个东西。

![图 9-1｜GTG 与 Daily Dose：方法不同，底层原则一致。](/images/posts/sfg-hardstyle/gtg-daily-dose-loop.png)

*图 9-1｜GTG 更像“全天分散练技能”，Daily Dose 更像“每天一小剂量正式训练”。*

#### GTG：把力量动作当技能练

GTG 最适合**单一、技术要求高、可以随时完成的动作**，比如 Pistol、OAPU、Pull-up。

StrongFirst 对 GTG 的要求可以压成四条：

1. **高频率。** 同一天反复接触同一个动作。
2. **每组远离力竭。** 对自重次数型动作，可以把每组控制在当前最大次数的大约一半。
3. **组间隔很长。** 不是 2–3 min 的普通力量训练休息，而是至少隔十几分钟，甚至一两个小时再做下一组。
4. **技能不要铺太多。** 同一个 GTG 周期最好只盯 1–2 个动作。

GTG 不等于“必须做单次”。真正的标准是：

> **每一组结束时都应该觉得轻松、动作干净，而且完全没有累积疲劳。**

一个最简单的执行流程：

```text
先确认当前标准动作能力
        ↓
每组只做约最大次数的一半
        ↓
把组数分散到全天
        ↓
组间至少隔很久
        ↓
动作速度 / 技术开始下降 → 当天停止增加
```

例如一个动作最大能做 6 次，GTG 不需要每次都做到 5–6 次，而更适合每次只做 2–3 次，然后一天出现很多次。

#### “运动零食”怎么落地

```text
选定 1 个技能
    ↓
把器械放在每天会经过的位置
    ↓
路过时做一小组完全干净的重复
    ↓
离开
    ↓
很久以后再做下一组
```

关键不是“今天总共刷了多少”，而是：

> **全天做完以后，你仍然觉得自己没有真正训练过。**

如果第二天明显酸痛、动作变慢、关节开始不舒服，说明 训练已经过火了。

#### Daily Dose：每天一小剂量正式训练

Daily Dose 更适合硬拉、推举这类**需要长期保持技术和力量，但又不能占用大量恢复资源的正式力量动作**。

StrongFirst 的 Daily Dose Deadlift 给了一个很清楚的模板：

| 项目 | 官方模板 |
| --- | --- |
| 主体重量 | 大部分训练约 75% 1RM |
| 工作量 | 3–5 个单次，即 3–5 × 1 |
| 频率 | 一周 5 天左右 |
| 组间休息 | 约 1–2 min |
| 热身 | 2–4 个轻重量单次 |
| 原则 | 状态一般做 3 个，状态好做 5 个；始终保持技术和速度 |

不是说所有 Daily Dose 都必须照抄 75% × 3–5 singles，而是说明它和 GTG 的差别：

|  | GTG | Daily Dose |
| --- | --- | --- |
| 组织方式 | 全天分散 | 每天一次很短的正式训练 |
| 更适合 | 自重技能、单一高技术动作 | 杠铃 / 壶铃主力动作 |
| 单次容量 | 极低 | 很低 |
| 组间休息 | 很长，常以十几分钟到小时计 | 正常力量训练休息即可 |
| 核心目的 | 高频练技能 | 维持 / 缓慢推进力量 |
| 共同底线 | **不疲劳、不力竭、重复必须干净** | **不疲劳、不力竭、重复必须干净** |

#### 平台期怎么用

如果一个动作已经卡住，而你现在的训练是：

```text
频率低
+
单次训练量很大
+
每次都练得很累
```

也许可以尝试反过来：

```text
降低单次训练容量
        ↓
提高训练频率
        ↓
保持每次都很新鲜
        ↓
4–6 周后重新评估
```

> **一句话：几乎每天都练，但从来不把自己练废。**

### 36. Variety Day：主计划之外的“技术复习日”

**教程视频：** [BV1qEuU6oEfY](https://www.bilibili.com/video/BV1qEuU6oEfY)

> 主计划越极简，越需要一个低压力窗口维护那些暂时没有被主计划覆盖的动作和角度。Variety Day 不是随机乱练，而是**有目的地补空白。**

![图 9-2｜三层训练结构：主力日、多样性日、每日微量。](/images/posts/sfg-hardstyle/variety-day-three-layer.png)

*图 9-2｜三层训练结构：最重的刺激集中在主力日，其他训练只做补充。*

Variety Day 主要做三件事：

| 任务 | 实际做法 |
| --- | --- |
| 技术维护 | 复习当前主计划里没有安排的动作 |
| 主动恢复 | 用轻到中等负荷活动身体，但不制造新的疲劳 |
| 补相邻角度 | 用壶铃、单侧、不对称和不同姿势训练主动作遗漏的位置 |

可以选择撬动式高脚杯深蹲、TGU、风车、轻抓举、挺举等动作，但只有一个判断标准：

> **练完之后，下一次主训练应该更好，而不是更差。**

Variety Day 不是第二个主训练日。不要因为“今天只是轻练”就把动作越塞越多。

#### 三层结构

```text
主力训练日
中高负荷，发展当前核心能力
        ↓
Variety Day
轻—中负荷，技术维护 + 补空白
        ↓
Daily Dose / 自重微量
极低容量，只维持动作熟练度
```

顺序不能反过来：**先把核心力量练强，再谈多样性。**

### 37. 正念训练：把注意力也当成训练变量

**教程视频：** [BV1xsbD6FEqY](https://www.bilibili.com/video/BV1xsbD6FEqY) · [BV1gnbX6rEwf](https://www.bilibili.com/video/BV1gnbX6rEwf)

> 正念在训练里的落地并不复杂：**每一次重复都知道自己在做什么；做完该做的，就停止。**

![图 9-3｜一组高质量训练的注意力闭环。](/images/posts/sfg-hardstyle/mindful-rep-loop.jpg)

*图 9-3｜准备—预演—执行—恢复。*

#### 四个可以直接执行的时刻

| 时刻 | 做什么 |
| --- | --- |
| TGU 准备 | 用无负重或很轻的动作慢慢走一遍路径，感受支撑点和身体排列 |
| TGU 执行 | 只处理眼前一个节点，不抢速度 |
| Swing 组前 | 先用几次呼吸把状态稳定下来，再在脑中预演一次干净动作 |
| Swing 执行 | 只盯关键 Cue 和呼吸，不边练边想别的事情 |

一个非常实用的组前流程：

```text
站好
  ↓
3 次呼吸把心率和注意力收回来
  ↓
脑中预演一次完整动作
  ↓
完成高质量重复
  ↓
休息到可以再次专注
```

#### 做少的勇气

真正的极简不是“偷懒”，而是主动删掉低质量内容：

- 不为了凑数补最后几次变形重复；
- 不因为今天状态好就临时加一堆动作；
- 不把休息时间压缩到技术开始下降；
- 不用训练数据证明自己“够努力”。

#### 训练纪律：只记四句话

1. **重量是裁判。** 做不到就是做不到，不靠解释改变事实。
2. **力量要服务主项和生活。** 它不是独立存在的奖杯。
3. **纪律是按计划做正确的事。** 不是每天追求最刺激的事。
4. **没人监督时也保持标准。** 训练质量首先是对自己的约束。

### 38. 格斗力量训练：专项负责“会打”，力量训练负责“有东西可打”

**教程视频：** [BV1MTby6EEZP](https://www.bilibili.com/video/BV1MTby6EEZP)

> 格斗训练已经给了你大量专项技能刺激。力量训练的任务不是复制拳击动作，而是补充**基础力量、爆发、拉力、握力和身体控制。**

![图 9-4｜格斗力量训练随比赛临近逐步让位给专项。](/images/posts/sfg-hardstyle/combat-season-priority.png)

*图 9-4｜离比赛越近，力量训练越要“退到幕后”。*

#### 最小动作框架

每周两次力量训练时，只需要覆盖四类动作：

| 模式 | 任务 |
| --- | --- |
| 髋铰链 | 爆发与后链力量 |
| 深蹲 | 下肢力量 |
| 推 | 上肢推力与全身张力 |
| 拉 | 背部、握力与肩带平衡 |

不需要按“胸日、背日、手臂日”拆分。

#### 建设期：距离比赛 8 周以上

训练重点仍然是变强：

- 深蹲 / 铰链：3–5 组，重复次数按 **6 → 5 → 4 → 3** 做四周波浪；
- 推 / 拉：3–5 组，重复次数按 **10 → 8 → 6 → 4** 做四周波浪；
- 重量永远停在技术能够稳定控制的范围内；
- 不练到力竭。

一个简单的两日拆分：

```text
Day A：髋铰链 + 拉
Day B：深蹲 + 推
```

#### 竞赛期：距离比赛不足 8 周

动作不必大换血，主要减少力量训练的存在感：

- 深蹲 / 铰链：2 × 6–8；
- 推 / 拉：2 × 8–10；
- 负荷降到轻—中等；
- 比赛前 4 周内不要引入全新动作。

对于拳击，优先级可以进一步压缩成：

> **Swing / 铰链 + 俯卧撑或推举 + 少量跳跃。**

专项拳击已经负责速度、时机和技术。力量训练只需要把这些技能背后的发动机练强。

### 39. 受限环境训练：装备越少，越要抓住动作模式

**教程视频：** [BV1ZTbC6tEFi](https://www.bilibili.com/video/BV1ZTbC6tEFi) · [BV1FNb16BEaU](https://www.bilibili.com/video/BV1FNb16BEaU)

> 极端受限环境里，目标首先是**维持已经拥有的能力**。完全停练通常比训练量下降更糟。

![图 9-5｜装备受限时的训练决策树。](/images/posts/sfg-hardstyle/minimal-strength-decision-tree.png)

*图 9-5｜先看手里有什么，再选最小可执行方案。*

#### 先守住四层能力

```text
一般力量
   ↓
爆发力
   ↓
耐力
   ↓
专项技能 / 时机
```

力量训练不应该跟技能训练抢恢复资源。大量循环、波比跳和高次数训练如果让动作速度和协调性明显下降，就已经偏离目标。

#### 原文给出的维持量参考

如果只是维持已经获得的力量，原文给出的参考是：

> **每周约 40–60 次高质量重复。**

重点不是死卡数字，而是理解：**维持需要的训练量明显低于继续建设新水平。**

#### 装备决策

| 条件 | 优先方案 |
| --- | --- |
| 有壶铃 + 可以做拉力动作 | 深蹲 + 推 + 拉，采用低次数阶梯 |
| 只有一只壶铃 | 单壶铃挺举 / Clean & Jerk 的低疲劳间歇 |
| 没有外部重量 | Pistol + OAPU + Pull-up / 划船替代 |
| 时间只有 15–25 min | 一个推、一个蹲、一个铰链、一个拉；全部低量 |

#### 15–25 min 极简模板

大多数普通训练日，每个动作 **2 × 5** 就够。

偶尔状态好，可以做：

```text
5 次
↓
稍加重量 3 次
↓
再稍加重量 2 次
↓
停止
```

原文给出的安全护栏很简单：

> **每次训练，每个动作总重复次数不超过 10 次。**

如果上一练已经偏重，下一次直接安排一个很轻的 **1 × 10**，让身体活动开即可。

#### 只有自重时

- Pistol：2–3 组 × 3–5 次；
- OAPU 变式：2–3 组 × 3–5 次；
- Pull-up / 替代拉力：3–5 组 × 3–5 次。

没有外部重量时，进阶主要靠**改变杠杆和支撑条件**，而不是硬凑更多次数。

### 40. 耐力项目也需要力量：目标是更省，而不是更累

**教程视频：** [BV11eb16mE1F](https://www.bilibili.com/video/BV11eb16mE1F)

> 力量训练对耐力最实用的价值，是让同样一次蹬地、划水或踩踏的相对成本变低。目标不是用力量训练替代跑步、游泳或骑行，而是让专项动作更经济。

![图 9-6｜力量训练如何支持耐力表现。](/images/posts/sfg-hardstyle/endurance-strength-framework.png)

*图 9-6｜力量负责提高“每一下”的质量，专项耐力负责把它维持得更久。*

只记三个方向：

| 方向 | 实际意义 |
| --- | --- |
| 动作经济性 | 腿、髋和躯干更强，同一配速下每一步相对更轻 |
| 后备力量 | 疲劳后仍有额外力量储备维持姿势和输出 |
| 身体平衡 | 用铰链、单侧动作和拉力补长期单一专项的动作偏科 |

#### 单壶铃“力量有氧”模板

选一只能够舒适推举约 10 次的壶铃：

```text
左：Clean → Press → Front Squat
放下，快速放松
右：Clean → Press → Front Squat
放下，快速放松
循环
```

选择能够长期维持的节奏，持续 **20–30 min**。重点是从头到尾保持动作干净，而不是追求喘到极限。

#### 如果耐力是主项

原文给出的完整框架是：

- 3 次力量训练；
- 1 次力量有氧；
- 1–2 次专项耐力训练；
- 至少 1 天休息 / 主动恢复。

如果耐力只是辅助能力，就不必照抄这个总量。只保留力量训练和必要的专项耐力即可。

### 41. Peak：目标日前两周，不再“练新能力”

**教程视频：** [BV13Wud6qEfw](https://www.bilibili.com/video/BV13Wud6qEfw)

> Peak 的任务不是继续建设，而是**把已经拥有的能力带到目标日。**

![图 9-7｜目标日前两周的峰值时间线。](/images/posts/sfg-hardstyle/peak-two-week-timeline.png)

*图 9-7｜越接近目标日，越应该减少疲劳和意外。*

#### 三不原则

1. **不尝试新东西。** 新食物、新补剂、新装备、新热身流程都不要临时加入。
2. **不临时补课。** 最后一周无法弥补之前几个月缺掉的训练。
3. **不测试极限。** 目标日前的 PR 测试只会增加疲劳和风险。

#### 两周时间线

| 时间 | 重点 |
| --- | --- |
| T-14 左右 | 完成最后一轮真正高强度训练 |
| T-7 左右 | 用轻量方式模拟比赛 / 测试顺序、时间和流程 |
| 最后一周 | 总量明显下降，只保留技术感和身体状态 |
| 最后 2–3 天 | 轻活动 + 恢复，不做极限训练 |
| 目标日 | 只负责表现，不再学习 |

模拟的是**流程**，不是极限：

- 按比赛项目顺序训练；
- 尽量在接近比赛的时间段训练；
- 提前固定热身、装备和补给；
- 不在模拟日测试最大值。

另外一个常见错误是完全躺平。减量不等于停止活动；轻量活动通常比连续几天完全不动更容易保持身体状态。

### 42. 伤病后重返训练：先恢复动作，再恢复重量

**教程视频：** [BV1WJgM6ZERB](https://www.bilibili.com/video/BV1WJgM6ZERB)

> 伤病康复首先服从医生 / 康复师给出的禁忌和负重限制。在这个边界内，重返训练仍然遵循熟悉的逻辑：**从能控制的最低起点开始，逐级增加。**

![图 9-8｜重返力量训练的四阶段路径。](/images/posts/sfg-hardstyle/rehab-return-path.jpg)

*图 9-8｜动作 → 轻负荷 → 阶梯建设 → 表现。*

#### 四阶段

| 阶段 | 重点 |
| --- | --- |
| 1. 恢复动作 | 无负荷或极轻负荷；呼吸、活动范围、基本动作模式 |
| 2. 重新加载 | 从明显偏轻的重量开始，线性、缓慢增加 |
| 3. 阶梯建设 | 先把当前重量练稳，再升级；轻日只负责技术和频率 |
| 4. 回到表现 | 只有需要比赛 / 测试时才进入峰值阶段 |

#### 重建时的三个硬规则

1. **当前重量必须先完全可控。**
2. **任何一组都不要追到技术崩坏。**
3. **轻训练日不能和重训练日抢恢复资源。**

#### 局部伤病：不要把整个身体一起“停机”

如果只有一侧肢体受伤，而且医生允许其余部位训练，可以：

- 继续训练健康侧；
- 换用不会给伤处增加负荷的动作；
- 尽量保留原来需要的基本动作模式；
- 不为了“保持训练感”偷偷给伤处加压。

核心目的不是在伤病期继续刷 PR，而是**尽量减少整体能力的流失，等伤处允许后再重新接回主训练。**

### 43. 长期训练：把“抗衰老”翻译成三个可练能力

**教程视频：** [BV1YqgL6bEHp](https://www.bilibili.com/video/BV1YqgL6bEHp)

> 长期训练不需要追求复杂指标。最值得长期保留的，是**握得住、站得稳、起得来。**

![图 9-9｜长期身体能力的三个支柱。](/images/posts/sfg-hardstyle/longevity-three-pillars.png)

*图 9-9｜握力、姿势 / 身体控制、从地面起身能力。*

| 能力 | 可以怎么练 |
| --- | --- |
| 握力 + 全身拉力 | Tactical Pull-up、悬挂、负重搬运 |
| 姿势与多角度控制 | 风车、俯身推举、单侧训练 |
| 从地面起身 | TGU、坐地起身能力 |

长期训练的重点不是不断刷新 1RM，而是维持：

- 足够的力量储备；
- 正常可用的关节活动；
- 左右侧控制；
- 从地面、低位和不稳定姿势重新站起来的能力。

随着恢复能力下降，训练剂量更应该“够用就停”：

> **用最低能够持续产生进步的剂量，而不是用最高能够勉强承受的剂量。**

伤病后重新建设同样如此：先用容量和动作质量把基础找回来，不急着靠高强度证明自己“恢复了”。

### 44. FMS：筛查的目的不是给自己诊断，而是决定“现在该练什么”

**教程视频：** [BV1eZgN6NEsi](https://www.bilibili.com/video/BV1eZgN6NEsi)

> FMS 是 Functional Movement Screen，作用是**筛查动作模式中的疼痛、明显受限和左右差异**，帮助你决定哪些动作可以正常训练、哪些要先降级处理。它不是医学诊断。

![图 9-10｜FMS 七项筛查与训练决策。](/images/posts/sfg-hardstyle/fms-seven-screen-decision.png)

*图 9-10｜先筛查，再决定：正常训练、暂时修正，还是交给医疗专业人员。*

#### 七项筛查到底看什么

| FMS 项目 | 大白话看什么 |
| --- | --- |
| Deep Squat | 全身能不能在双脚支撑下协调下蹲 |
| Hurdle Step | 单腿站立时，骨盆和身体能不能保持稳定 |
| Inline Lunge | 分腿姿势下的髋、膝、踝控制 |
| Shoulder Mobility | 两侧肩带活动是否明显受限 / 不对称 |
| ASLR | 一条腿抬起时，另一侧和骨盆能不能保持稳定 |
| TSPU | 做俯卧撑时，躯干能不能整体移动而不塌腰 |
| Rotary Stability | 四点支撑下，身体能不能控制旋转和左右协调 |

不需要把七项筛查背成考试题。真正有用的是后面的处理顺序。

#### 最简单的决策规则

```text
筛查动作
   ↓
有没有疼痛？
 ├─ 有 → 停止对这个模式继续加负荷，找专业人员评估
 └─ 无
      ↓
有没有明显做不到 / 左右差异？
 ├─ 有 → 先降级动作、改善限制，再重新测试
 └─ 无 → 可以正常训练，并逐步增加容量和强度
```

FMS 官方的核心逻辑可以进一步压成：

| 结果 | 训练处理 |
| --- | --- |
| 疼痛 / 不适 | **Protect before Correct**：先保护，不在这个模式上继续硬练 |
| 明显受限或左右差异 | 技术和动作质量优先，暂时不要追负荷和容量 |
| 动作达到可接受水平 | 正常训练，不需要无限做“纠正训练” |

如果同时存在多个问题，**先处理左右差异，再处理单纯的双侧限制。**

![图 9-11｜训练负荷准备度检查清单。](/images/posts/sfg-hardstyle/load-readiness-checklist.png)

*图 9-11｜把疼痛、动作控制和左右差异放在加负荷之前检查。*

#### 对个人训练最实用的三个原则

1. **筛查不是诊断。** 它只告诉你“这里值得注意”，不负责告诉你具体是什么伤。
2. **纠正训练只是过渡。** 一旦动作模式恢复到可以训练的水平，就应该逐步回到真正的力量训练。
3. **定期复查，而不是天天筛查。** 如果你针对一个明显限制做了调整，隔一段时间重新测试，确认有没有变化。

> 上负重之前最重要的不是“所有关节必须完美”，而是：**没有疼痛、没有明显失控、技术可以稳定重复。**

### 45. 044 抓举协议：短爆发 + 大量恢复


> 044 的重点不是把抓举做成连续 MetCon，而是**把短促的高质量爆发分成小块，中间给足恢复。**

![图 9-12｜044 抓举：2 min 工作窗口 + 2 min 恢复。](/images/posts/sfg-hardstyle/qd-044-snatch.png)

*图 9-12｜每个 4 min block 只有前 2 min 做功，后 2 min 完整恢复。*

最直接的执行方式：

```text
00:00  5 次抓举
00:30  5 次抓举
01:00  5 次抓举
01:30  5 次抓举
02:00–04:00  休息
```

也就是：

> **2 min 完成 20 次抓举 + 2 min 恢复 = 1 个 4 min block。**

如果做 5 个 block：

- 总抓举：100 次；
- 每 20 次之间都有完整恢复窗口；
- 整体不是靠乳酸堆积硬顶，而是尽量维持每一组的速度和爆发。


#### 三条执行底线

1. **抓举必须已经熟练。** 044 不是拿来学习抓举动作的。
2. **每组都应该像第一组。** 一旦握力、锁定或轨迹明显变差，就不该继续堆数量。
3. **休息属于训练内容。** 不要因为“感觉还能练”就在那 2 min 里加波比跳、划船或其他动作。

> 044 的核心不是“20 次有多累”，而是**20 次之后还能恢复到足够新鲜，再复制下一轮高质量输出。**
